# Refonte site services — Routeur

1. Lire `state.md` → trouver le numéro d'étape courante
2. Lire le fichier correspondant dans `.agents/workflows/refonte/etape-{N}-*.md`
3. Exécuter les instructions
4. Mettre à jour `state.md`: marquer l'étape ✅, passer à la suivante

Fichiers disponibles:
- `refonte/etape-1-setup.md` — TypeScript + Design Tokens + globals.css
- `refonte/etape-2-layout.md` — Migration CV /cv + Layout Header/Footer + _app.js
- `refonte/etape-3-accueil.md` — Page d'accueil (Hero, Services, Process, About, CTA)
- `refonte/etape-4-accompagnement.md` — Page accompagnement (Timeline interactive)
- `refonte/etape-5-contact.md` — Page contact (formulaire + Cal.com)
- `refonte/etape-6-polish.md` — Animations GSAP, SEO, responsive, Lighthouse
